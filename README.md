# mjsply

## ツール情報
麻雀AI対戦サーバ「Mjai」向けのクライアントツール

### 開発状況
かつて存在した「mjai.app」の閉鎖に伴い現行バージョンにて開発を終了します。  
一部不具合修正等を除いて、Githubでのアップデートは終了とします。  

### 開発環境
 * OS         ： LinuxMint22.3
 * ビルド環境 ： Python3.14

## 実行手順：ruby用Mjaiサーバの場合

```
$ python mjscli.py
```

### Pythonでのビルド手順
```
cd mjs/src/
sh -x build_py.sh
```

```
ls -l build/lib.linux-x86_64-3.10
```

### Python向け仕様
 * ret = init(int id)：初期化
 * snd_mes = react(res_mes)：受信メッセージに対するアクション決定(送信メッセージ決定)
